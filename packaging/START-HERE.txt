BUG REPORT HELPER - Windows 64-bit offline demonstration
演示日期：2026 年 11 月 26 日（周四）

1. 完整解压 ZIP 到桌面或其他可写文件夹，不要直接在压缩包内启动。
2. 双击 StartDemo.cmd，等待浏览器自动打开。保持启动窗口开启。
3. 浏览器没打开时，复制启动窗口显示的 http://127.0.0.1:端口/ 地址。
4. 双击 DEMO-GUIDE.html 查看演示顺序、四人讲解建议和故障处理。
5. 结束时在启动窗口按 Ctrl+C。再次启动会保留已有演示报告。
6. Evidence/ 保存验证摘要、日志和应急截图，可在断网时展示。

从 1.0.0 升级：关闭旧启动窗口，再把旧包 demo-data 中的
demo-reports.db 复制到新包的 demo-data 文件夹后启动。保留旧包作为备份。
在已保存报告点击 Edit report 或缺失字段旁的 Add 链接即可补填。

免安装：内置 Windows x64 Python；无需 pip、Node.js、网络或管理员权限。
演示数据：首次启动生成 4 条虚构 Study Planner 报告；不是同伴研究结果。
运行数据：demo-data/demo-reports.db。不要把真实个人信息写入演示。
重置：先停止程序，再双击 ResetDemo.cmd，输入 RESET 确认。
重置前会在 demo-data/backups/ 保存 SQLite 备份；不会改其他数据库。
自检：双击 CheckDemo.cmd，不会改变演示数据。
端口占用会自动换到可用端口；重复双击会打开同一工作区。

For an English demonstration script and rehearsal checklist, open DEMO-GUIDE.html.
Build identity and source hashes: BUILD-INFO.json.
